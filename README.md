Plataforma Digital para la Gestión Integral de Servicios Médicos Comunitarios
Descripción:
Hospital Digital es una plataforma web modular orientada a la gestión integral de servicios médicos comunitarios. 
El proyecto busca centralizar diferentes procesos relacionados con la atención y administración, principalmente la gestión de citas,
registro de usuarios, seguimiento básico de indicadores de salud, consulta de información médica, orientación nutricional y un asistente 
virtual basado en Inteligencia Artificial. La plataforma se desarrolla mediante una metodología ágil, permitiendo realizar pruebas durante 
el desarrollo y efectuar ajustes conforme se identifiquen necesidades, errores o riesgos.

Objetivo general:
Desarrollar, integrar, probar y validar una primera versión funcional de una plataforma web que centralice servicios médicos comunitarios, 
facilitando la gestión de usuarios, citas, información médica básica, seguimiento de indicadores de salud y orientación nutricional, mediante 
una arquitectura cliente-servidor y herramientas como React, PHP y MySQL.

Instrucciones generales para consultar el proyecto:
Requisitos
Para consultar el proyecto será necesario contar con
1- Un entorno de desarrollo compatible con React.
2- PHP para el backend.
3- MySQL para la base de datos.
4- Conexión a Internet para las herramientas o servicios que lo requieran.

Configuración
1- Clonar o descargar el repositorio.
2- Configurar el frontend desarrollado con React.
3- Configurar el backend desarrollado en PHP.
4- Crear y configurar la base de datos MySQL.
5- Configurar la comunicación entre frontend, backend y base de datos.
6- Ejecutar las pruebas correspondientes.
7- Verificar los módulos y flujos principales de la plataforma.
